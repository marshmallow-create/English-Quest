# English Quest — 開発仕様書 v1.0

## 目的
中学1〜3年の英単語・英文法を、1回5〜10分のゲーム形式で継続学習できるレスポンシブWebアプリを提供する。

## 現状
既存 `index.html` は単一HTML/CSS/JSのオフライン試作。学年ごと英単語5問・文法5問、合計30問。4択、正誤表示、解説、復習キュー、localStorageで回答数・正答数・学習回数を記録。`english-quest-v1` キーを使用。

## 利用者・利用環境
- 中学1〜3年生。主な端末はスマホ、PC、タブレット。
- 日本語UI、英語問題・日本語解説。キーボードでも操作できること。
- 初期版は登録不要。ユーザーデータはブラウザごとに保存し、別端末同期はしない。

## 画面構成
1. ホーム: 学年選択、累計XP、レベル、今日の進捗、連続学習日数、コース入口。
2. 単元選択: 学年→英単語/英文法→単元。単元名、問題数、正答率を表示。
3. クエスト: 1回最大10問。問題→選択肢→判定と解説→次の問題。進捗バー、得点。
4. 結果: 正解数、正答率、獲得XP、間違えた問題、再挑戦。
5. 復習: 間違えた問題を優先。正解後は復習対象から外す（将来は間隔反復へ）。
6. 記録: 学習日数・連続日数・累計解答数・累計正答率・単元別正答率。

## ゲーム仕様
- 英単語正解 +10 XP、英文法正解 +15 XP。誤答 +0 XP。
- 5問連続正解するたび +20 XP（1クエスト中で最大2回）。
- レベルは `floor(totalXp / 100) + 1`（初期仕様）。
- 日付は端末のローカル日付で処理。学習完了を1日1回カウントし、翌日にも学習した場合だけ連続日数を増加。同日複数回は増やさない。
- XPは回答時に確定し、画面再描画や再読込で二重加算しない。回答後の選択肢は操作不可。

## コンテンツ
- 中1: 基礎語彙、be動詞、一般動詞、疑問文、三単現、現在進行形。
- 中2: 学校・社会・感情語彙、過去形、未来表現、不定詞、動名詞、比較。
- 中3: 抽象語彙、現在完了、受動態、関係代名詞、分詞。
- 当面は既存30問を保ち、次段階で各学年100問／計300問を目標とする。教科書による学年差を考慮し、出題データとUIを分離。
- 各問題の構造: `id`（永続固定）, `grade`, `category` (`vocabulary`/`grammar`), `unitId`, `prompt`, `options`（4個）, `answer`（正解選択肢の値）, `explanation`。
- 品質ルール: 正解はちょうど1個、選択肢重複なし、解説は日本語、学年不適合・曖昧な出題は修正。学年別の内容には教材差あり。

## データ構造
- `questions`: 問題一覧（コード内JSONまたは別JSON）。
- `progress`: `schemaVersion`, `xp`, `answered`, `correct`, `sessions`, `lastStudyDate`, `streakDays`, `studyDates`, `reviewIds`, `questionStats` (`[id]: {attempts,correct,lastAnsweredAt}`)。
- 既存localStorageの `english-quest-v1` から初回移行可能な項目を取り込む。移行不可能な古い履歴は無理に推測せず保持または明記する。
- 新しいストレージキーは `english-quest-v2`。読み込み失敗時は安全な初期値へフォールバック。

## 非機能要件
- スマホ幅320px以上、タッチしやすいボタン、十分な文字コントラスト。
- 正解表示を色だけに依存しない。aria属性、フォーカス可視化、適切な見出し。
- 外部CDN/APIなし、ビルド不要、ローカルの `index.html` で起動できること（ファイル読み込み制約に注意）。
- 個人情報収集なし。localStorageの限界（端末固有、削除で消失）を明示。

## 受け入れ条件（STEP 1）
1. 中1〜中3と英単語・英文法の6通りで学習でき、単元選択が可能。
2. 毎回10問以内で終了、回答→解説→次へ、結果画面まで動く。
3. XP・連続正解ボーナス・レベルが仕様どおりで、リロードで二重計上しない。
4. 誤答した問題は復習に入り、復習時の正解で復習対象から外れる。
5. 学習履歴が再起動後も保存される。旧データで破損しない。
6. スマホとPCでレイアウトが崩れない。キーボードで操作できる。
7. 開発後に変更ファイル・動作確認結果・未対応課題が報告される。

## 開発ロードマップ
- STEP 1: UIゲーム化、単元選択、XP、復習、履歴（現行のHTMLベース）
- STEP 2: 300問へ拡充、問題品質レビュー、簡単な学習分析
- STEP 3: React + TypeScript移行の要否判断、Supabaseで任意ログイン・履歴同期、デプロイ
- STEP 4: 音声問題、AI添削、適応型復習（予算・プライバシーを確認して導入）
