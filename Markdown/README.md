# English Quest — STEP 3

中学1〜3年生向けの、ユーザー名・パスワードでログインして使う英語学習アプリです。

公開先：**https://english-quest-sepia.vercel.app/**（Vercel本番デプロイ）

## 起動

公開URLを開き、ユーザー名とパスワードでログインしてください。新規登録も同じ画面から行えます。ゲスト学習はありません。画面を開いた際は保存済みセッションもサーバーで確認し、確認できるまでは学習画面や成績を表示しません。起動時のログイン確認には通信が必要です。

ソースの`index.html`を直接開いた場合、接続設定がないためログインできません。開発時は`.env.example`を参考に公開用の接続情報を環境変数へ設定してビルドし、`dist/`をHTTPで配信してください。学習の途中で通信が途切れた場合は、端末に記録を保持して後で同期できます。

ホームで学年とコースを選び、全単元または個別単元からスタートします。4択に回答すると正誤と日本語解説が出ます。「次の問題へ」で進み、最後は「結果を見る」で正答率・獲得XPを確認できます。

## 実装内容

- 中1・中3は各学年100問（英単語50問・英文法50問）。中2はExcel教材の英単語271問・英文法100問へ置換。合計571問／27単元。全単元・単元別とも、収録問題からランダムに1回最大10問を出題。
- 中2の271語は`momo_choice_英単語一覧20261020.xlsx`の空行を除いた表記・順序を保持し、熟語・会話表現も一つずつ正解として出題。200問への絞り込みより全271語の出題を優先する、というユーザー回答を反映しています。
- 中2の英文法はリストの語句・場面を使ったオリジナル100問、10単元。現在完了はseen・been・eaten・since・yetに対応する「発展」単元として収録。
- 英単語正解10 XP、英文法正解15 XP、5問連続正解ごとに追加20 XP（1回のクエストで最大2回）。レベルは `floor(XP / 100) + 1`。
- 誤答問題を復習に登録。通常演習・復習のどちらでも、正解で解除。復習はホームで選んだ学年が対象。
- 回答時にXP・累計回答数・正答数・問題別の選択肢／正誤／回答日時を保存。二重回答は無効。
- 最後の問題に回答した時点で、完了クエスト数と学習日を保存。端末のローカル日付で連続日数を計算。同日に複数回完了しても学習日数は増えません。
- 学習記録で累計成績、単元別正答率、問題ごとの回答履歴を確認。
- 学習記録の「学びの振り返り」で、選択中の学年の挑戦済み問題数・一度でも正解した問題数・未挑戦数を表示。同じ問題を繰り返しても挑戦済み問題数は増えません。
- 直近7日間の日別回答数と期間内正答率を全学年で集計。回答日時がない旧版の集計値は含めず、回答がないときの正答率は「—」で表示。
- 選択中の学年で復習対象が多い単元を最大3件提示。同数なら累計正答率が低い順。単元に再挑戦するボタンと、苦手問題だけを復習するボタンを用意。対象学年はホームで変更できます。
- 暗い青・紫を基調とするレスポンシブUI。装飾アニメーションとホバー時の移動を抑え、問題文のコントラストは7:1以上を確認。320px以上、キーボード操作、判定後のフォーカス移動、動きを減らすOS設定に対応。
- 「学習記録」下方の「データ管理」から学習記録のJSONを書き出し・取り込み。取り込みは内容を確認してから実行し、置き換え前の記録を退避します。ヘッダーは「ホーム」「学習記録」のみで、ログアウトはホーム下部に配置しています。
- ユーザー名・パスワードによるログインが必須。メールアドレス・確認メール・SMTP設定は不要です。アカウントの端末内記録を分離し、ログアウト・認証切れでログイン画面に戻ります。以前のゲスト記録は削除せず、ログイン後に「データ管理」から確認して取り込めます。
- 英単語は正誤に関係なく、出題の解説に加え4つの選択肢すべての意味・品詞を表示します。中2の271語には全語に使い方の補足も付けています。英文法も正解・不正解の両方で「解説」欄を必ず表示し、復習でも同様に確認できます。
- 回答時は端末に保存し、その後クラウドへ同期。通信失敗時は未同期の端末記録を保持。「同期する」で再試行できます。同時更新は版番号で検知し、端末・クラウドのどちらを使うか選びます。XPを自動で足し合わせません。

最初の画面でユーザー名とパスワードを入力し、「新規登録」を押すと、そのままログインします。以後は同じ情報で「ログイン」を押します。ユーザー名は半角英字・数字・`_`の3〜24文字で、大文字・小文字は区別しません。パスワードは半角英数字・記号8〜64文字です。パスワードの再設定は今回の対象外です。詳細は [STEP 3記録](STEP3_REVIEW.md) を参照してください。

## 保存と旧版移行

以前のゲスト保存キー`english-quest-v2`と`english-quest-v1`は移行用に保持します。通常の起動では読み込まず、ログイン後の明示的な取り込みだけに使います。現在の記録は`english-quest-account-<利用者ID>`に保存し、クラウド上では認証利用者が所有する1行として保存します。ブラウザデータの削除やプライベートモードでは端末内の未同期記録が失われる場合があります。ブラウザが保存を許可しない場合は画面に通知し、ログイン中はメモリ上で学習を続けます。

ログアウト後も、未同期の記録を失わないため端末内のアカウント記録は保持します。共有端末で端末内の控えも消す場合は、必要な記録をバックアップしてからブラウザデータを削除してください。JSONバックアップにパスワードや認証トークンは含みません。

STEP 1の作業開始時、フォルダーには `SPEC.md` と `CODEX_PROMPT.md` だけがあり、旧試作の `index.html`・旧30問・Git管理情報はありませんでした。そのためSTEP 1では新規の30問を作成しました。旧試作と比較はできていません。STEP 2では、そのSTEP 1の30問と保存キー・スキーマを維持しています。

`english-quest-v2` がない初回のみ、`english-quest-v1` の次の非負整数を移行します。

| 移行先 | 読み取る旧項目（左を優先） |
| --- | --- |
| `answered` | `answered` / `totalAnswered` |
| `correct` | `correct` / `totalCorrect`（回答数を上限とする） |
| `sessions` | `sessions` / `studyCount` |
| `xp` | `xp`（旧正答数からの推定加算はしない） |
| `reviewIds` | 今回の問題IDと一致するIDのみ |

旧ソースがないため、上記以外の形式、旧問題IDの対応、学習日の復元は行いません。旧キーは削除・変更しません。問題別履歴・連続学習日数は新規に記録します。旧集計を移行した場合、累計と新しい単元別記録の合計が一致しないことがあります。移行範囲は画面でも表示します。

壊れたv2データ・未対応のスキーマは初期値へ戻し、原文を `english-quest-v2-recovery` に退避します（保存可能な場合）。元データの復元に必要なときは、このキーと旧キーを削除しないでください。

途中でホームへ戻る・再読み込みをした場合、その回答までのXP・履歴は残りますが、途中のクエストは再開しません。連続正解はクエストごとにリセットされます。

## 検証

Node.js 22以上で、外部パッケージなしで実行できます。

```powershell
npm test
node scripts/build.js
node scripts/test-built.js
```

ブラウザテストはWindowsの標準的なEdgeインストール先を使用します。別のChromium系実行ファイルを使う場合は `EDGE_PATH` を設定してください。ブラウザがない場合はスキップします。一時プロファイルを使用し、普段使っているブラウザのデータには触れません。確認画像は `tests/artifacts/` に出力します。

確認対象：571問の整合性と配分、Excel271語との表記・順序照合、全語の正解出題、文法100問と元語彙の対応、中1・中3の旧教材保持、中2の旧IDを再利用しないこと、全問の正解・誤答と復習登録／解除、3学年×2コース、27単元、XP・連続正解・日付境界、旧版保存データ互換性、同期・認証・バックアップ、320px／375px／1280px、Enter・Tab操作。

## Vercelへの公開

外部依存パッケージなしの静的サイトとして公開しています。Node.js 22で `node scripts/build.js` を実行し、出力先を `dist` に設定します。ビルドは公開用ファイルだけをコピーし、テスト・Git情報・環境ファイル・バックアップを公開出力に含めません。

本番環境変数は `SUPABASE_URL`、`SUPABASE_PUBLISHABLE_KEY`、`SUPABASE_SIGNUP_ENABLED=true` です。ブラウザに公開する値だけを設定し、書き込み権限はSupabaseのRLSで制御します。秘密キー・`service_role` キーはVercelやクライアントに設定しません。新規環境ではDBと`username-auth`関数を先にセットアップします。認証用の秘密キーはSupabase Edge Functionのサーバー内だけで使用します。

React・TypeScriptへの全面移行は見送り、既存のHTML/CSS/JavaScriptとゲーム処理を維持しています。現在はログイン必須のため、利用には接続設定を含む公開版を使用します。

## 残課題

- 元の `index.html` と匿名化した旧保存データを確保し、元の30問の取り込み・実データでの移行互換性を確認する。
- 利用する教科書に合わせて学年配当と語彙を確認する。中2の語句は指定Excelと一致を確認済み。文法・訳語の作成時レビューと自動検査は実施済みですが、教員による校閲は未実施です。公開済み問題のIDは変更・再利用しない。
- iOS Safari・Android実機、スクリーンリーダーでの読み上げは未検証。file://での保存はブラウザ依存のため、利用端末で確認する。
- 途中クエストの再開は未実装。
- パスワード再設定・アカウント復旧は、ユーザー指定により今回は対象外。メール・SMTPの設定作業は不要。
- Vercelは本番デプロイのREADYを確認済み。ユーザーから公開URLのホーム画面表示も確認済み。接続ツールの一部の参照APIが403となるため、この環境からの本番ブラウザ操作・ビルドログ取得は未確認。

STEP 3ではユーザー指定に従ってSupabase専用プロジェクトを作成し、Vercelへ直接デプロイしました。Gitのコミット・PushとAI APIの導入は行っていません。
