# Codexへの実装指示｜English Quest STEP 1

あなたは既存の中学生向け英語学習Webアプリ「English Quest」を改修する開発担当です。**最初に現在のリポジトリと `index.html` を確認してください。既存機能を壊さず、動くSTEP 1を実装してください。**

## 現状
元の試作は単一 `index.html`（HTML/CSS/JavaScript）。中1〜中3、英単語・英文法各5問、全30問。4択、正誤・解説、間違えた問題の復習、localStorageの学習回数・回答数・正答率が動作しています。旧保存キーは `english-quest-v1` です。

## 目的
対象は中学1〜3年、デザインはゲーム感覚で楽しく、主な内容は英単語と英文法。毎日5〜10分学習でき、スマホでも操作しやすいWebアプリにしてください。UIは日本語、問題文は英語と日本語を適切に使い分けます。

## 必須実装
1. ホーム画面をゲーム風に刷新する。学年・英単語/英文法選択、XP、レベル、連続学習日数、学習実績を表示する。
2. 問題ごとに固定ID、学年、カテゴリー、単元ID、問題文、選択肢、正解、解説を持たせ、問題データを表示コードから分離する。既存30問は消さず、正解の一意性を確認する。
3. 単元選択画面を追加する。既存30問は内容に応じた単元へ分類し、問題不足でも正常に動くこと。
4. 1クエストの出題は最大10問。問題回答後に正誤、正解、短い解説を示し、次へ進む。最後に結果画面を表示する。
5. 正解XP: 英単語10、英文法15。5問連続正解ごとに20の追加XP（1クエスト最大2回）。レベルは `Math.floor(xp/100)+1`。
6. 誤答問題は復習一覧に登録し、復習クエストで正解したら対象から除く。通常クエストで再正解した場合も除く。
7. 累計回答数・正答数・クエスト完了数・設問別正答履歴・連続学習日数を `localStorage` に保存。新キー `english-quest-v2` を使い、旧キー `english-quest-v1` から可能な範囲で一度だけ移行する。データ破損に安全に対応する。
8. レスポンシブデザイン。320px幅でも横スクロールなし。キーボード操作、適切なラベル・フォーカス表示を備える。
9. 見た目は爽やかな青・紫系を基調に、カード、進捗バー、小さな演出を使う。過度なアニメーションは避け、動きを減らすOS設定を尊重する。
10. 外部API、認証、DB、課金は追加しない。まずオフラインで動く軽量版を完成させる。

## 実装進行
- まずリポジトリを調べ、変更計画を短く示す。
- 既存のコード構造に合わせ、必要なら `index.html`, `style.css`, `app.js`, `questions.js` に分割。ただしブラウザの `file://` 起動でも動く構造を維持する。依存関係の追加は最小限。
- 問題や履歴を扱う関数を分離し、二重回答・二重XP・空の復習・データ破損などを防ぐ。
- テスト: 中1〜中3、各コース、最初/最後の問題、正答/誤答、復習登録/解除、連続正解ボーナス、再読み込み後の保存、旧データ移行、スマホ幅、キーボード。
- 実行可能なテストを実施し、できなかった確認は明記する。

## 制約
- 既存機能と保存済みの学習データをできるだけ保護する。
- リポジトリにないファイルを勝手にあるものとして扱わない。
- 問題数を無理に300問へ増やさない。今回は品質とゲームの基本機能を優先する。
- 勝手に Git commit/push、Render/Vercelデプロイ、外部サービス変更をしない。
